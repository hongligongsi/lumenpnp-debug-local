列表缺少摄像头时如何检查

使用桌面 Chrome / Edge 打开 http://localhost:8765/，点击“授权 / 刷新摄像头”并允许本站访问摄像头。检查地址栏的摄像头权限，以及 Windows 设置 → 隐私和安全性 → 摄像头中的访问权限和桌面应用访问权限。关闭占用摄像头的 OpenPnP、会议软件或其他网页后重试。

摄像头与设备连接独立。上摄像头朝下看 PCB，下摄像头朝上看吸嘴；请根据实际画面选择设备。

指令与通信配置

预置：Marlin 点动 / 回零；P0 左泵、P1 左阀、P2 右泵、P3 右阀。先核对实际接线。上下灯默认共用 M150。每行一条指令；这里的占位符与 OpenPnP 格式不同。

配置保存在当前浏览器；仅断开设备后可修改。默认 M410 快速停止；M112 会进入需复位的停机状态。

宏指令序列

每行一条 G-code，以 ; 开头的行为注释。可用占位符：{X} {Y} {Z}（当前坐标，需先读取坐标）、{xyStep} {zStep}、{feed} {feedZ}。占位符在发送前替换；这里的写法与上方「指令配置」里的 OpenPnP 风格格式互不影响。名称为空或指令为空的条目在保存时会被丢弃。

宏按钮与「允许硬件控制」联动，未启用控制时不可点击。宏保存在当前浏览器，并随「导出全部设置」一起备份。
