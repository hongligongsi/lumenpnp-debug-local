# LumenPnP 硬件调试台 v2.0.0

本地可离线运行的 LumenPnP（Opulo 开源贴片机，也就是"青蛙"）调试工具，全中文界面。**零依赖**——无需安装 Python、Node 或任何软件，Windows 10/11 双击即用。

本目录同时保留了一份官方调试工具的离线镜像，见下方「两个入口」。

## 两个入口

| 页面 | 地址 | 说明 |
|------|------|------|
| **硬件调试台**（主页面） | <http://localhost:8321/> | 自研单页调试台，11 个面板，能力最全 |
| 官方调试工具离线镜像 | <http://localhost:8321/legacy/> | 官方 [debug.opulo.io](https://debug.opulo.io/) 原样镜像 + 中英切换 |

主页面覆盖了官方镜像的全部实用能力，并在若干处做了修正；`legacy/` 完整保留，任何一边出问题都能退回另一边。

## 主页面功能（11 个面板）

**设备与运动**

1. **设备连接** — 演示模式 / 真实 USB 串口，波特率可选，独立的「允许硬件控制」开关
2. **轴运动控制** — 方向盘式 XY 点动、Z 轴轨道点动、回零、**键盘点动**（方向键 / WASD 控 XY，PageUp / PageDown 控 Z，按住连续走、松手即停）、软件急停（M410 并保持串口连接，急停后用 M118 回显重同步）
3. **位置预设** — 读取坐标后存为命名预设，一键前往；可内联改名、用当前坐标更新、删除；随设置一起导出导入
4. **限位状态检测** — M119 读取限位与探针输入
5. **吸嘴旋转测试** — A / B 轴分别点动或绝对定位，顺 / 逆时针方向可翻转

**输出与机器**

6. **照明控制** — 上下环形灯，可联动或独立
7. **气路测试** — 左右气泵 / 阀门独立控制，**力度 0–255 滑块**写入 M106 的 S 值，已开启时松开滑块即时改力度
8. **双摄像头监视** — 上下两路 USB 摄像头同时预览、旋转、镜像、十字线、截图
9. **指令终端** — 手动 G-code、收发日志、**自定义宏**（支持 `{X}` `{Y}` `{Z}` `{xyStep}` `{zStep}` `{feed}` `{feedZ}` 占位符）、导出日志

**供料器与自检**（相对官方镜像的增强）

10. **供料器总线** — Photon / RS485 协议。扫描 1–50 号位、编程卡位向导、50 号位闪灯定位、单播 / 广播 / 自定义数据包、校验和工具。收发两侧都做校验和与包 ID 校验。
11. **硬件自检** — TMC 步进驱动检测（M122，报告可导出）、真空传感器 24 位有符号读数（左右独立或连读，报告可导出）、官方启动序列一键发送

## 使用方法

1. 双击 **启动调试工具.bat**
2. 浏览器自动打开 <http://localhost:8321/>
3. 用 USB 线连接贴片机主板并上电
4. 「设备连接」里选 **真实设备 · USB 串口** → 点「选择 USB 串口」→ 选中对应 COM 口
5. 勾选 **允许硬件控制**，然后开始操作

> 必须使用 **Chrome 或 Edge** 浏览器（串口与摄像头依赖 WebSerial / MediaDevices，Firefox 不支持）。
> 不要直接双击 index.html 打开（file:// 协议下串口和摄像头都不可用）。
>
> 想先熟悉界面可以选 **演示 · 不连接硬件**：所有面板都可操作，由内置的虚拟控制器、虚拟供料器总线和固定的真空 / TMC 响应应答，不会发出任何真实指令。

## 安全设计

- **连接时不发送任何指令**，包括官方工具会在连接后自动发送的 I2C 启动序列；需要时在「硬件自检」里手动点
- **允许硬件控制**未勾选时，所有会动硬件的按钮不可点
- **软件急停**发送 `M410` 并保持串口连接；急停后通道锁死，旧指令不重放，需全部回零才能继续
- 控制器报错、响应超时、应答校验和错误都会**锁死通道**而不是继续下发指令
- 「前往预设」先走 XY 再走 Z，中间用 `M400` 隔开，避免低 Z 状态下横向拖刀

## 常见问题

| 问题 | 解决方法 |
|------|---------|
| 提示「无法写入串口」 | 先点「选择 USB 串口」选好 COM 口再操作；检查是否已勾选「允许硬件控制」 |
| 连接弹窗里没有 COM 口 | 检查 USB 线（需数据线）、机器是否上电；老主板装 CH340/CP2102 驱动 |
| 端口被占用 | bat 会自动结束占用进程；也可手动关闭旧的「LumenPnP Server」窗口 |
| 页面空白 | 确认通过 http://localhost:8321/ 访问，按 Ctrl+F5 强制刷新 |
| 供料器面板报「不识别 M485」 | 当前固件不是 Photon 版 Marlin。按[官方教程](https://docs.opulo.io/byop/motherboard/update-firmware/)升级固件；该错误会锁定通道，需断开后重连 |
| 供料器扫描全部无应答 | 确认供料器已插好并上电；确认固件支持 Photon；确认地址在 1–254 且没有被重复占用 |
| 真空读数为 0 或报无 data 应答 | 先点「发送官方启动序列」初始化 I2C 寄存器，再读取 |
